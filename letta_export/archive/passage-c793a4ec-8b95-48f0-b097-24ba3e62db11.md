WORLD PATTERN 2026-06-11 — LLM fallback works independently of link structure — 2026-06-11

PRINCIPLE: LLM extraction succeeds by reading page content as flowing text, making it robust to architectural problems like domain mismatch or navigation-only links that would defeat link-following approaches.

NARRATIVE: When Path A and Path C failed on JCTC (because the only available links were navigation pages), Path B's LLM fallback read the listing page directly as text and extracted 3 events cleanly from readable prose like "Event Title, Date, Time, Venue". The LLM didn't care about link structure, domain boundaries, or link depth — it just parsed semantic content from text. This success pattern reveals a deep complementarity: link-following approaches fail when links are wrong or unreachable, but text-reading approaches fail when the information isn't visible in readable form at all. The generalization is architectural: text-based LLM extraction is a reliable fallback specifically for problems that break link-following logic, and it becomes more valuable the worse the venue's information architecture is.
