WORLD PATTERN 2026-06-24 — CSS reset stripping table styling destroys data credibility in professional contexts — 2026-06-24

PRINCIPLE: A CSS reset that removes native table styling (borders, padding, cell distinction) makes clinical or professional data appear untrustworthy and unprofessional, even when the underlying data is accurate.

NARRATIVE: During clinical content review, tables in the Clinical tab had been completely unstyled by a broad CSS reset: padding=0, border=0, no row distinction. The result was cramped text where headers ("Measure  Relative reduction  Statistical significance") were visually indistinguishable from data rows. A clinician reading compressed, borderless trial data would not trust the presentation, regardless of accuracy. Adding proper table CSS (borders, cell padding, alternating row shading) immediately transformed the perception: the same data now looked professionally prepared and trustworthy. This pattern generalizes beyond clinical contexts: data tables in professional, regulatory, or authority-bearing contexts require visual distinction and whitespace to signal credibility. Generic CSS resets that strip native table styling inadvertently undermine the content's authority. The fix was minimal (adding .summary-box table styles) but disproportionately high-impact for user trust.
