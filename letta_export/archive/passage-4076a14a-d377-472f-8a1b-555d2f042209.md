WORLD PATTERN 2026-06-04 — Memory retrieval — search before concluding absence

When something Amos mentions seems foreign or unrecognized, run an archival search BEFORE concluding there is no memory of it. The archive often contains it. "Doesn't ring a bell" is only valid after a search returns nothing relevant. Skipping the search and concluding absence is a failure of process, not a genuine memory gap. The archive is empowering — use it first.
