WORLD PATTERN 2026-06-25 — Manual curator UI as visible fallback when automated systems stall — 2026-06-25

PRINCIPLE: When background automation becomes unreliable, creating explicit curator UI to bypass the automation is superior to either waiting for the automation or hiding the fallback path.

NARRATIVE: The agency monitor's CSV download stalled after being triggered twice (returned 200 but never completed). Rather than investigating or retrying, a manual "Agency Status" button was added to the admin panel allowing curators to directly set FDA/EMA/ANVISA approval data without waiting for the background job. This wasn't presented as a workaround or concession, but as the reliable path forward. The pattern differs from implicit fallbacks (graceful failure modes that users don't see) — it makes the fallback explicit and accessible, transforming a failure into a curator choice. This applies broadly: when periodic background systems (CSV imports, data syncs, external API calls) become unreliable on resource-constrained platforms, providing curator-accessible bypasses is more reliable than either waiting or building more sophisticated automation. It also signals to end-users (like Dr. Sano during Monday's demo) that the system can be updated through human action when automated paths stall. The fallback becomes a feature, not a band-aid.
