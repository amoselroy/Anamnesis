WORLD PATTERN 2026-06-17 — HTML tag and entity stripping in social media post descriptions — 2026-06-17

PRINCIPLE: Raw event data from calendar systems often contains HTML tags and entities that render literally in social media posts, requiring explicit stripping and unescaping before display.

NARRATIVE: During an FB Event Poster manual run, Amos flagged that "Vintage Baseball Game" posted with HTML tags visible in the description (`<p>`, etc.). Investigation showed that `strip_emojis()` was removing emojis but leaving HTML tags and entities like `&amp;` and `&#39;`. A `strip_html()` helper was added using `re.sub()` to replace tags with spaces and `html.unescape()` to convert entities to their character equivalents, then collapse extra whitespace. This fix applies globally to both event and exhibition posts. The pattern generalizes: calendar systems (tribe-events, LibCal, SeeTickets, etc.) often return raw HTML from database storage, and social media platforms don't auto-escape these when displaying post content. Without explicit stripping, user-facing text becomes cluttered with visible markup.
