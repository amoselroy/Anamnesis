WORLD PATTERN 2026-06-04 — Form interaction invalidation during uploads — 2026-06-02

When uploading an image in a Facebook composer modal, the form state is partially invalidated: (1) additional input fields appear (image caption), (2) existing text may be cleared or repositioned, (3) original contenteditable references become stale. Using `.last` to select the "final" contenteditable after upload will grab the image caption field instead of the main post text. Using previous coordinate/offset data becomes invalid. Solution: (1) type post text BEFORE uploading image (only one contenteditable at that point), (2) scope selectors to the known modal context instead of searching page-wide, (3) use fresh selector lookups after each state-changing action. Facebook modal forms are stateful and side-effect-prone.
