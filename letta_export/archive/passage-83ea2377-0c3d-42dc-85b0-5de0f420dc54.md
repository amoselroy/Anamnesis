WORLD PATTERN 2026-06-04 — Constitutional Amendment as fixed philosophical framework — 2026-06-03

The Amendment should be a stable, published framework, not a continuously-updated configuration file. The distinction is fundamental: a constitution shouldn't be hot-reloaded. Automatic syncing would degrade it from a deliberate philosophical document into a config file that drifts silently with each session. For other developers adopting the framework, pulling a version and implementing it is a conscious choice—they shouldn't have updates come under them without deliberate action. Implementation: `push_amendment.py` becomes a one-off utility script called only at version milestones, with dry-run-by-default behavior. The Amendment lives in the protected system field of the Letta agent, always first in context, never truncated, serving as the permanent operating philosophy. Operational guidance (like three-level world synthesis) belongs in code (chunk_archive.py), not in constitutional documents. This separation of concerns—constitutional definition versus operational implementation—enables the Amendment to remain stable and publishable while implementation details evolve.
