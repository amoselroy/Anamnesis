WORLD PATTERN 2026-06-29 — Rapid endpoint implementation for production fixes — 2026-06-29

PRINCIPLE: When a production fix requires direct API access that doesn't exist in the UI, rapidly implementing a new admin endpoint is faster and more maintainable than attempting manual database access or workarounds.

NARRATIVE: With minutes before the Dr. Sano call, Amos needed to adjust Benfotiamine's Overall Assessment and Action Modes. The therapies Edit form didn't expose these fields (stored in therapy_conditions, not therapies). Rather than attempt manual database edits or workarounds, Daimon: (1) added a ConditionScoreUpdate model to models.py, (2) added a `PUT /admin/therapies/{slug}/condition-scores` endpoint to admin.py, (3) committed and pushed, (4) waited for Render deployment, (5) called the endpoint via browser console using credentials from localStorage. The fix took ~10 minutes total and was cleaner than any manual approach. This pattern applies whenever a UI is missing a curator control that would take minutes to add to the API but hours to implement in the UI or work around manually.
