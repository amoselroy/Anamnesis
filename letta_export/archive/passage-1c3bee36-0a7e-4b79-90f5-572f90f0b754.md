SUMMARY
The final issue emerged when posts submitted successfully but source-type posts appeared without preview images and no spacing before the URL. Investigation revealed that Lexical's `insertText` command strips newlines from the input, causing multi-line text with a URL on the final line to land as a single continuous string where the URL splices directly onto the preceding text without a line break. The post format includes `\n\n` before the URL to create separation, but this was lost during insertion. The solution identified was to split post text on newline boundaries and use `insertParagraph` commands between text segments, treating each line as a separate insertion operation so Lexical's newline handling preserves the intended structure.
