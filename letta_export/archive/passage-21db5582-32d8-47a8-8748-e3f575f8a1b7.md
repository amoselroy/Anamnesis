WORLD PATTERN 2026-06-11 — Structured data serialization in delimited text fields — 2026-06-11

PRINCIPLE: Complex structured data can be encoded in a single text field using hierarchical delimiters (pipes separate keys, semicolons separate list items within values), enabling schema-free storage that a frontend parser can reconstruct without adding database columns.

NARRATIVE: The ICTRP trial notes field needed to capture multiple data types (phase, countries, status, contact information, enrollment form URL) without extending the schema. The solution was to serialize as pipe-separated key-value pairs where list values (multiple contacts) are semicolon-delimited: `Phase: X | Countries: Y; Y | Status: Z | Contact: name — email · phone; name2 — email | FormURL: URL`. The frontend `parseTrialNotes()` function lowercases all keys and splits the string by pipes and semicolons to reconstruct the structured data. This pattern trades schema simplicity for serialization complexity — particularly useful when data is optional, variable-length, or might change without database migrations. It works across iterations: old records with single contacts render correctly without updating the field, while new records can include multiple contacts automatically.
