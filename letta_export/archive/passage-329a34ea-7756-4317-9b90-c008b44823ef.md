This avoids scraping infrastructure for what is fundamentally hand-curated content. **JC Night Market** initially had Eventbrite subdomain URL (`jerseycitynightmarket.eventbrite.com`) which doesn't trigger the Path EB handler; Daimon found the correct organizer URL format (`eventbrite.com/o/13395292239`) and swapped it, allowing the scraper to pick up both events (Aug 1 and Oct 3). **Hoboken Family Alliance** had 6 events with extracted date/time but all were still rejected (date range issue — they're 2025 events posted before their website was updated for 2026). The site stores event details in prose on individual pages, requiring LLM extraction, which is already built into Layer 4. Amos noted they likely moved to Facebook; Daimon swapped the source to their Facebook page for Path FB handler to pick up. **Manual Sources sheet** was created in the spreadsheet to track sources requiring hand-curation (recurring events, sites that stopped posting, etc.). Multiple sources were added to this list. The refactoring immediately enabled new sources like Smush Gallery to work correctly.
