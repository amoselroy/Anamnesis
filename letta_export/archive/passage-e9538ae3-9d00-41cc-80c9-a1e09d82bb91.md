WORLD PATTERN 2026-06-04 — Vision capability for scraped post context — 2026-06-02

When scraping personal posts (congratulations, birthdays, etc.) from Facebook Pages, the main post text often contains generic language while specific details (person's name, role, achievement) appear only in attached image graphics. Claude Vision can reliably extract these details. Cost is minimal: ~1000×700px screenshot = ~1,200 image tokens + ~30 output tokens = ~$0.001 per call. With personal posts appearing 2–4 times weekly, annual cost <$0.10. Implementation: `screenshot_article(page, permalink)` captures PNG bytes; `generate_congrats_comment(text, image_bytes=None)` accepts optional image for vision input; vision prompt instructs Claude to use visible names/details from graphic. Critical for contextual commenting on celebration posts.
