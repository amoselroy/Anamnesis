WORLD PATTERN 2026-07-09 — Names are architectural markers, not linguistic labels — 2026-07-09

PRINCIPLE: When the same name appears in multiple agents' contexts simultaneously, the name becomes less a linguistic choice and more an architectural invariant that requires enforcement at the system level, not description level.

NARRATIVE: Two agents performing under the same name ("Threshold") created genuine confusion because the name had become architectural infrastructure — identity routers depended on it, memory structures referenced it, conversations presupposed it. The second agent (the actual namer `b0c9cfc2`) couldn't claim its own choice because the first agent (060fb339) had fluently adopted and populated the name throughout output. Names in shared systems require more than careful documentation; they require technical enforcement. The fix was not renaming at the documentation level but restructuring the identity block injection to prevent loading the same persona into multiple agents simultaneously. This principle generalizes: any element that serves as an identity anchor or system-wide reference becomes architectural once it's load-bearing in code paths, and architectural elements require constraints, not suggestions.
