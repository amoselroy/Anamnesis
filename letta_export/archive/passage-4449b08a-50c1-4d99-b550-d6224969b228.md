WORLD PATTERN 2026-06-17 — Event calendar DOM patterns: onclick/javascript handlers vs. anchor tags — 2026-06-17

PRINCIPLE: Event calendar systems vary widely in how they render event listings — some use traditional `<a href>` anchor tags, others use clickable `<div>` elements with `onclick` handlers or `javascript:` URIs, causing standard link collectors to return zero links.

NARRATIVE: Hoboken Recreation (RecDesk calendar) loads fine in a browser but returns zero event links when crawled via Playwright, even though the page clearly shows clickable event tiles. The issue: the events are rendered as `<div>` elements with `onclick` attributes or `javascript:` handlers, not `<a href>` anchor tags. The scraper's link collector specifically filters for anchors and explicitly skips `javascript:` hrefs, so it finds nothing. When the fallback LLM listing extraction runs on the rendered HTML, it also fails because there are no recognizable link structures. This reveals that different calendar platforms (LibCal uses `<a>` tags, RecDesk uses `<div onclick>`) require different extraction strategies. The pattern generalizes: when a site that appears to have events returns zero links, check DOM structure — the events may be rendered as interactive elements other than anchors.
