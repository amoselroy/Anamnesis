WORLD PATTERN 2026-06-04 — Markdown-to-HTML-to-Google-Docs-to-PDF: Reliable pipeline for formatted document export — 2026-06-03

PRINCIPLE: Google Drive auto-converts only text/plain to Google Docs; other formats require manual application routing, but this enables a tool-agnostic pipeline for producing formatted documents without external tools.

NARRATIVE: When converting Markdown documentation to PDF in an environment where Google Drive is the available tool, uploading .md files directly fails because Drive auto-converts only `text/plain` to Google Docs, leaving Markdown files unconverted and unformatted. The workaround discovered this session: convert Markdown to HTML using Python's `markdown` library with extensions, upload the HTML files to Drive, then manually open them with Google Docs (right-click → Open with → Google Docs), which renders HTML with full formatting preserved (headings, bold, lists, tables, code blocks), then export to PDF via File → Download → PDF Document. This pipeline was successfully tested when converting ARCHITECTURE.md, MODIFICATIONS.md, and SETUP.md. The generalizable principle: Drive's auto-conversion is limited to plain text; other formats require explicit application routing, but this enables a reliable, tool-agnostic pipeline for producing human-readable formatted documents without requiring PDF libraries or external tools. This pattern is reusable for any markdown-to-PDF workflow when Drive is the available tool.
