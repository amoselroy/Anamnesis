Design decisions established: (1) use ntfy.sh (free public/private topics, HTTP POST, no signup required) for push notifications since `PushNotification` tool is unavailable to unattended scripts; (2) flag "two consecutive failures" in source scraping logs to filter out one-off blips while catching persistent problems; (3) flag post failures only from the most recent FB poster run, deliberately not treating the large unposted backlog (503 old rows) as a failure since this represents normal curation behavior, not a pipeline break.
