SUMMARY
After the view restored, Amos reported that news articles still didn't show the `+/-/~` sentiment badges, weren't sorted by date (newest first), and no signal cards appeared on the dashboard. Investigation revealed that code was correct but data was the issue. Most existing news articles had `published_date = NULL` (the direct scrapers rarely return dates), and articles inserted before the `sentiment` column was added had `sentiment = NULL`. The sentiment badge function returned an empty string for NULL values, and NULL dates didn't sort correctly. The signal cards (effectiveness, safety, side effects, overall) only appear after `research_therapy()` or the summarize endpoint runs, which hadn't been done for Acetyl L-Carnitine yet. Additionally, a critical bug was discovered in the sources SELECT query — it wasn't fetching the `sentiment` column, so `s.sentiment` was always NULL in the API response regardless of what was in the database. The fix was a one-line addition: including `sentiment` in the SELECT. To properly populate old articles with dates and sentiments, a backfill endpoint would be needed (deferred). Running "Manage News → Fetch" on a therapy adds new articles with sentiment and correct dates; it doesn't retroactively fill old ones. This revealed that the architecture of having Manage News separate from Research was the right call, as it prevented curation deletions from being re-added during future research runs.
