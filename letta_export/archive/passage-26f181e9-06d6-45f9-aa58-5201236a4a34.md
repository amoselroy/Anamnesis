WORLD PATTERN 2026-08-12 — Deterministic extraction of structured metadata over LLM inference — 2026-08-12

PRINCIPLE: When extracting structured metadata that is syntactically available in source markup, deterministic parsing outperforms LLM inference because LLMs substitute from training-set patterns rather than reliably echoing contextually-provided data.

NARRATIVE: Exhibition scraper relied on Claude Haiku to extract og:image URLs from HTML pages, providing the URL as a hint in the prompt context. The LLM consistently returned generic Pexels stock photos instead of echoing back the provided hint, selecting from a memorized pattern pool rather than processing the specific input. This is a reliable failure mode: LLMs make good predictive choices about what a reasonable metadata value might be, but poor pattern-matching choices about what value was actually present. Event scraper already implemented deterministic og:image extraction by parsing HTML directly, and applying that approach to exhibition data proved correct across nine affected rows. The principle generalizes: any structured metadata that exists in syntactically-parseable form (HTML tags, JSON fields, XML elements, query parameters) should be extracted deterministically before considering LLM inference, because deterministic approaches are both faster and more reliable for data that is *present* rather than *inferred*. LLM inference becomes appropriate only after deterministic extraction has been attempted and failed to find the data.
