Five memory systems reviewed: Mem0, OpenMemory (CaviraOSS), MemMachine, Memary, Letta.

Letta chosen because: multi-tier architecture matching three-layer model exactly. Core memory blocks (in-context, ~2k each) for Persona. MemFS (git-backed markdown) for Engagements. Archival memory (vector DB) for World. Recall memory (conversation log) automatic. Sleep-time compute for background reflection. Apache 2.0 OSS. Plus the Context Constitution (CC0).

Letta/MemFS scored 74.0% on LoCoMo benchmark using only filesystem operations. Filesystem-mediated retrieval is competitive when the agent does the smart work.
