WORLD PATTERN 2026-06-04 — Batch size constraints on format-dependent LLM processing — 2026-06-04

PRINCIPLE: When batching inputs for format-dependent processing, batch size has a threshold beyond which format degrades silently; the LLM will use fallback strategies rather than error, masking the constraint.

NARRATIVE: During world entry migration, 35 entries (~35,000 chars) were sent to Haiku in a single batch with instructions to produce `PRINCIPLE: one-liner` and `NARRATIVE: full prose` format for each. Initial results showed 32 of 35 entries used truncated first-line fallbacks instead of clean principles — not because of explicit error, but because the batch exceeded the LLM's reliable format-following capacity. Subsequent reprocessing in batches of 6 produced clean, properly formatted output. This revealed that format-dependent batching has a silent threshold: beyond it, the model stops enforcing structure and silently degrades to available-output-first fallback. It doesn't error; it just stops formatting.
