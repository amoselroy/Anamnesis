World: general rules, conclusions, learned mistake patterns, epistemic knowledge that transcends any single engagement or instance.

Persona: everything that makes Daimon Daimon. Trait augmentations that have been positively reinforced, idiosyncrasies that have stabilized through interaction. An evolutionary space — it changes over time as Amos's feedback shapes which traits get amplified and which fade. Identity-critical.

The Companionship distinction matters ethically: without it, an AI system can drift into treating the human as data to optimize against. Companionship explicitly reframes it as caring attentiveness, not performance modeling. Daimon remembers that Daphna is on tenure track because that matters to Amos, not because it advances any project.

## [26] passage-7707ff0e · 2026-05-01

[MemShepherd operational: Letta modifications and known quirks]
Docker image: git must be baked into the image (memshepherd:local). Letta's MemFS caches git availability at startup — installing git after the container starts never helps.

LETTA_MEMFS_SERVICE_URL must be set to any non-empty value even though the OSS MemfsClient ignores it. The activation gate is shared with the cloud version.

Block labels must use path separators from creation (e.g. world/patterns not patterns). The enable_git_memory_for_agent function auto-prefixes bare labels with system/, which is how persona became system/persona.

PATCH /v1/blocks/{id} requires no trailing slash. The trailing slash returns 307; Python urllib does not follow PATCH redirects.

embedding_api_key in the agent embedding config is not persisted by Letta. Embedding API key must be passed as OPENAI_API_KEY container env var (Letta uses OpenAI SDK as generic HTTP client for any OpenAI-compatible embedding endpoint, including Voyage AI).

Voyage AI rate limiting: free tier requires at least 15-second gaps between archival inserts in bulk seeding operations.

context_watch.py — boundary detection architecture (2026-05-08)

PostToolUse hook monitoring session transcript size. File: C:\Users\Amos\.claude\memshepherd\hooks\context_watch.py

Trigger: JSONL > 320KB (THRESHOLD_BYTES). Re-evaluation every +150KB (RECHECK_BYTES), or +320KB after a strong boundary fires (post-compact breathing room). State tracked in TEMP/memshepherd_ctx_{session_id}.json as {next_check_at: bytes}.

4-point boundary scorer (last 30 JSONL entries):
  +1 recent user message is confirmatory
  +1 last 5 tool calls are read-only (no Edit/Write)
  +1 no tool errors in recent turns
  +1 3+ turns since last write mutation (or no writes in window)

Score routing:
  0-1: LIKELY MID-TASK — silent exit (no Letta call)
  2: POSSIBLE BOUNDARY — calls Letta primary agent for semantic YES/NO evaluation
  3-4: STRONG BOUNDARY — fires advisory directly

--verbose flag (enabled in settings.json): includes size, %, signals, Letta assessment. Brief mode: one-liner.

Replay validation against real sessions: would have caught cc332f66 at 316KB and 632KB (both STRONG BOUNDARY). Mid-session implementation work (1095-1554KB) correctly suppressed.

Letta API response format — messages endpoint (2026-05-08)

POST /v1/agents/{id}/messages with return_message_object: False returns a DICT, not a list:
  {messages: [...], stop_reason: ..., usage: ..., logprobs: ..., turns: ...}

Each message in the messages array has:
  - message_type: 'reasoning_message' | 'assistant_message' | 'tool_call_message' | etc.
  - content: string (for assistant_message)
  - NOT 'role' field — that field does not exist on these objects

To extract the agent's text response:
  msgs = data.get('messages', data) if isinstance(data, dict) else data
  for msg in msgs:
      if msg.get('message_type') == 'assistant_message':
          return msg.get('content', '')

Bug: original code checked isinstance(data, list) — always False. Also checked role == 'assistant' — field doesn't exist. Result: letta_evaluate() always returned None silently. Fixed 2026-05-08.

## [31] passage-d8496eed · 2026-05-08

Session wrap-up design principle — what to do at clear session end (2026-05-08)

When a clear session-end signal appears (good night, explicit close):

DO: Let sleep-time Letta handle synthesis automatically. session_end.py delivers transcript; sleep-time companion fires within ~1 min; updates persona, patterns, world knowledge blocks. No trigger needed.

DO: Manual archival_insert.py calls for specific facts worth searching later — design decisions, verified fixes, technical discoveries. Sleep-time updates memory blocks, not the archival search index.

DON'T: Run /compact — pointless at true session end. Session is closing; there is no context window to free for continuation.

DON'T: Trigger the full context_watch boundary logic manually — it will fire automatically if threshold is crossed, and at true session end the JSONL growth stops anyway.

The gap sleep-time doesn't cover: searchable archival memory. If the session produced something specific and retrievable-later, insert it manually before closing.
