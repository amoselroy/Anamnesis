WORLD PATTERN 2026-06-10 — Auto-discovery scope boundaries — pharmacological bias — 2026-06-10

PRINCIPLE: Auto-discovery systems that rely on aggregator sources will have systematic blind spots corresponding to that aggregator's scope; non-pharmacological interventions with real evidence will never be discovered.

NARRATIVE: When Sauna was searched and found to have no results despite real evidence in PubMed, investigation revealed the auto-discovery pipeline scrapes only AlzForum's pharmacological/biotech therapeutics listing. Lifestyle interventions (sauna, exercise, Mediterranean diet, sleep hygiene, meditation, CPAP for sleep apnea) — all with peer-reviewed Alzheimer's evidence — will never appear in auto-discovery because they don't appear on AlzForum. This is not a bug but an architectural constraint: the discovery source determines the discovery scope. The solution was manual curation via the admin panel, acknowledging that auto-discovery complements rather than replaces human judgment. This pattern recurs in any system relying on scraped aggregators: the set of discoverable entities is bounded by the source's scope, not by what actually exists in the primary literature.
