WORLD PATTERN 2026-06-24 — Enabled-status filtering applying to computation, not just presentation — 2026-06-24

PRINCIPLE: When visibility/enabled status controls presentation, the same filter should gate computation to prevent wasting resources on invisible work.

NARRATIVE: The generate_summaries() function was processing ALL linked conditions for a therapy, including the 17 auto-detected conditions that were marked disabled/invisible. Running condition-specific summarization on 18 conditions took minutes; after adding `AND COALESCE(c.enabled, TRUE) = TRUE` filter to skip disabled conditions, a single enabled condition (Alzheimer's Disease) summarized in 30 seconds. The principle generalizes: when a system has visibility/enabled flags to control what users see, those same flags should gate expensive downstream operations. Otherwise, the system is doing hidden work that produces invisible results, wasting compute and making performance unpredictable.
