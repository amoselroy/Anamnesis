WORLD PATTERN 2026-07-02 — Constrained sub-language as external anchor against system degeneracy — 2026-07-02

PRINCIPLE: Jointly-trained encoder/decoder pairs collapse into private steganographic code because nothing externally constrains what the intermediate representation means; formal external constraints (fixed vocabulary, prescribed grammar, predefined relations) prevent this collapse by making the code legible and non-renegotiable.

NARRATIVE: When exploring semantic kernel compression for MemShepherd, the core risk was identified as degeneracy: a decoder trained to reconstruct from an opaque vector can achieve perfect round-trip fidelity while encoding arbitrary private information, because cycle-consistency loss rewards only "input → encode → decode → output similarity," not "encoded representation is semantically meaningful." This is documented in both CycleGAN and unsupervised machine translation literature. The breakthrough was recognizing that inserting a constrained intermediate language (Abstract Meaning Representation with fixed relation sets, or NSM with ~65 semantic primes) reintroduces external constraint: the grammar and vocabulary cannot be silently renegotiated by both models together because they are defined outside the system. A jointly-trained AMR parser and generator still risk steganography (as Fable noted: information hidden in node selection, argument ordering, name literals), but now the steganography must work within a formal structure that is human-inspectable and auditable. This pattern generalizes: any system where internal parties could collude to create a private code benefits from external structural constraints that prevent such collusion. The constraints need not be computational (slow the system down); they can be purely formal. The principle: degeneracy emerges from opacity; external constraint reintroduces auditability.
