WORLD PATTERN 2026-06-10 — Semantic sort ordering vs alphabetical — 2026-06-10

PRINCIPLE: Column headers in tables should sort by semantic meaning (domain-specific ordering) rather than alphabetically, especially for fields where the display text differs from the meaningful sort order.

NARRATIVE: The evidence level column in the sortable therapies table was initially set to sort alphabetically ("Observational" → "Phase 1" → "Phase 2" → etc.), but the meaningful order for clinical strength is Phase 3 (strongest evidence) down to Preclinical (weakest). A domain-aware sort shows the most rigorous evidence first without alphabetical artifacts distorting the ranking. This applies broadly: dates should sort chronologically (not by text representation), clinical stages should sort by evidence strength (not alphabetically), categorical data should sort by a defined hierarchy, not by how the labels happen to be spelled.
