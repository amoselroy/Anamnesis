WORLD PATTERN 2026-06-04 — Facebook events as a scrapable source — 2026-06-04

Venues with active Facebook events pages but no functional website can be added to a scraper's sources as `facebook.com/VenueName/events`. The structured event format Facebook displays ("Sat, Jun 20 at 12 PM / Event Title / Venue Address") is regex-parseable and consistent. Implement a dedicated scraper path that uses a saved Playwright session (the same session the posting bots already use for authentication) to load the page and extract the text. This works reliably for venues where the primary website is broken/inaccessible/doesn't exist. Rate-limit Facebook source scraping to 1-2 per run to avoid attracting bot detection, but no special precautions are needed beyond standard rate limiting — Facebook doesn't appear to block automated event page reads when using a legitimate browser session. This creates a useful fallback: if a venue's website becomes inaccessible, its Facebook page can immediately take over without code changes.
