WORLD PATTERN 2026-08-11 — Edge-case acceptance with monitoring alert instead of silent filtering — 2026-08-11

PRINCIPLE: When data violates a strict requirement but remains semantically valid and useful, accept it while generating a monitoring alert for visibility, rather than silently filtering it.

NARRATIVE: The FB date-regex fix revealed that Facebook sometimes provides event dates without times, violating the scraper's datetime requirement. Rather than continuing to silently drop these timeless events, the system removed the time-requirement gate and allowed them to post while adding an ntfy alert on each timeless post. This inverts the typical pattern where invalid data gets filtered invisibly; instead, it acknowledges that "timeless event" is a legitimate edge case users might want to see, while creating visibility for curation and investigation. The curator can now decide whether timeless events add value rather than having that decision made implicitly by filtering. The principle applies wherever strict conformance creates unwanted data loss—relax the requirement at aggregation and compensate with increased observability upstream.
