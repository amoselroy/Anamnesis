SUMMARY
During the clean poster run, Amos reported that "Malik Work - verses at work" posted with a blank image and "White Eagle Hall events" posted with a generic repeated image. Investigation revealed two distinct image problems: (1) "Malik Work" had `Image Type: source` with a SeeTickets CDN image URL, but the Facebook poster doesn't upload for "source" type — it falls back to link preview, which Facebook can't scrape from SeeTickets (blocked), so a generic SeeTickets fallback image was used instead; (2) "White Eagle Hall" rows had `Image Type: generic` with Unsplash placeholder URLs, indicating the actual event image was never fetched. The scraper was inspected and found that "generic" is never assigned by the scraper itself — only "source" or "none" — so those rows had been set manually at some point. The root cause for SeeTickets rows was identified: when the scraper encounters SeeTickets CDN image URLs, it was assigning `Image Type: source` (expecting link preview to work), but Facebook can't render those links. The fix: scraper modified to assign `Image Type: native` when the URL is from SeeTickets CDN, so the image gets uploaded directly. A backfill script was written to (1) flip all existing unposted "source" rows with SeeTickets CDN URLs to "native", and (2) Playwright-fetch the detail pages for "generic" rows to extract the actual event image. The first run succeeded in flipping 13 existing rows from "source" to "native", but crashed on a unicode character (→) in the final print statement. The second run hit the same unicode issue in a different location and failed to extract images from SeeTickets pages (Playwright returned empty content). The third run completed successfully with the unicode fixed, confirming that 13 rows had been flipped to "native" in the first run (skipped on re-run since they were already "native"), but the 4 "generic" rows still had no actual images extracted due to Cloudflare blocking headless Playwright requests to SeeTickets. Amos decided those 4 remaining rows should be set to `Image Type: none` so they fall back to Pexels event-type-specific images rather than posting with generic Unsplash placeholders. The 13 "source→native" flip is permanent and will work going forward when the poster re-runs.
