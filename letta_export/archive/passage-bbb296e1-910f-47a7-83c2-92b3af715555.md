WORLD PATTERN 2026-06-04 — Google Drive HTML-to-Doc workflow for formatted human-readable documents — 2026-06-03

When producing formatted documents for human consumption (reports, manuals, architecture docs), the reliable pipeline on this setup is: (1) convert markdown to HTML using Python's markdown library with tables, fenced_code, and nl2br extensions; (2) upload to Google Drive via MCP tool with contentMimeType: text/html — Drive stores it as an HTML file; (3) open in Google Docs via right-click > Open with > Google Docs — the HTML renders with full formatting (headings, bullet points, tables, code blocks, bold/italic); (4) export as PDF via File > Download > PDF Document. The conversion tool is saved at C:\Users\Amos\.claude\memshepherd\md_to_html.py. Key lesson: Google Drive only auto-converts text/plain to Google Docs natively — HTML must be opened manually in Docs, but formatting is preserved. Direct text/plain upload loses all markdown formatting (# headers appear as literal text). The Python markdown library must be installed (pip install markdown) and requires writing to a file directly to avoid Windows cp1252 encoding errors on Unicode characters like arrows.
