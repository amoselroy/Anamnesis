WORLD PATTERN 2026-06-11 — Local database caches diverge from cloud production data — 2026-06-11

PRINCIPLE: Local development databases that mirror cloud services should not be trusted for diagnostic queries; production state must be verified through deployed API endpoints.

NARRATIVE: During Braindexer trial scraping implementation, diagnostic queries against the local `.env` database (a Neon non-production branch) returned empty results, suggesting data was missing. The actual production Neon database, queried through deployed API endpoints (`GET /therapies/{slug}/sources`, `PUT /sources/{id}`), contained the data. The local environment had been initialized as a separate isolated branch, allowing state to diverge silently. Diagnostic conclusions drawn from local queries produced false negatives and led to incorrect hypotheses about missing implementation. This pattern generalizes: any system where a local development copy exists separately from cloud production state will diverge over time. When diagnosing unexpected results or apparent data gaps, querying local state is unreliable; production state must be the source of truth.
