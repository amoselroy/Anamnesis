SUMMARY
User reported that the homepage shows "No therapies" when filtering by Alzheimer's Disease despite the database showing 5 therapies linked to it. Investigation revealed 45 auto-detected conditions in the filter dropdown, of which 44 are disabled (created by auto-discovery but not yet curated). Selecting any of the disabled conditions returns zero results as expected. The underlying issue was discovered to be the condition dropdown including disabled conditions, which had zero linked therapies. Applied fix: filtered the condition dropdown query to show `enabled=true` only, and added an optional `?enabled_only=true` parameter to the `list_conditions` endpoint so the index page can request only enabled conditions for the dropdown while the admin still has access to all conditions. This ensures users only see conditions with actual therapy links, while the 44 auto-detected conditions remain in the database and appear as chips on individual therapy pages. The "no therapies" issue persisted even after this fix when selecting Alzheimer's itself, indicating an unresolved problem in either the `list_therapies` query or the connection/transaction handling in `get_connection()`.
