WORLD PATTERN 2026-06-06 — Duplicate semantic structures created after form state mutations — 2026-06-06

PRINCIPLE: Complex form interactions can create multiple DOM nodes with identical semantic attributes, making single selectors ambiguous after state changes.

NARRATIVE: After uploading an image to Facebook's post composer, the DOM contained two distinct Lexical editor elements, both with `data-lexical-editor="true"` and `aria-placeholder="Write something..."` — one for the post body text and one for the image alt-text field. A selector matching both was ambiguous. Initial attempts using `.click(strict=False)` failed, and visibility-based filtering (getBoundingClientRect) picked the wrong one. The root cause was that the file upload state change triggered Facebook's React to render a second editor with identical semantic attributes. The fix required being explicit: `.first` to select the first match, or additional filtering criteria to distinguish them. This generalizes: after substantial form state changes (file uploads, modal compositions, complex interactions), new DOM nodes with the same semantic attributes may appear; single selectors become ambiguous and require additional specificity or context to resolve.
