WORLD PATTERN 2026-06-11 — Stub pages with only external links and no contextual event data — 2026-06-11

PRINCIPLE: When a venue's events page contains only external platform links (e.g., Eventbrite redirects) with zero contextual event information (no dates, times, or venue details), all scraping paths fail and the source should be removed from the collection.

NARRATIVE: Hudson Theatre Works presented a different failure mode than other unscrappable sources. Unlike JCTC (nav pages with potential LLM extraction) or WFMU (wrong link format but correctable via URL fix), Hudson Theatre Works's tickets page is essentially a stub: it contains only 2 external Eventbrite links with zero event data visible on the page itself. Path A fails because external links are filtered out; Path B (LLM listing extraction) fails because there is nothing to extract — no dates, times, or venue information appear on the page as readable text; Path C would find the same external links and be unable to fetch them. Additionally, the venue (Weehawken, NJ) is geographically outside the target area. This represents a boundary case: the page is structurally unsuitable for scraping because it serves only as a redirect portal. The decision is not to build a technical fix, but to remove the source from the collection. This pattern generalizes: stub pages that function as link aggregators without containing the aggregated data themselves are unsuitable for event scraping, regardless of technical approach, and should be identified and removed rather than debugged.
