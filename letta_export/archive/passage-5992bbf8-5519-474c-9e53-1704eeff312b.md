WORLD PATTERN 2026-06-11 — Playwright listing page overlay for carousel/JS-rendered catalog sites — 2026-06-16

PRINCIPLE: Some sites require Playwright rendering not for individual detail pages but for the listing page itself (e.g., JavaScript carousels, SPAs, dynamic widgets), and benefit from a dedicated override set to force listing-page Playwright rather than relying on detail-page fallbacks.

NARRATIVE: Visit Hudson County's events are displayed in a JavaScript carousel. Static HTTP fetch returned only 1 event; Playwright revealed 4 event links. Rather than hardcode a workaround, a `_PW_LISTING_DOMAINS` set was created for domains where the listing page itself needs Playwright rendering. This enables the scraper to catch all carousel events going forward when they rotate. The pattern generalizes: many CMS platforms (Wix, React SPAs, dynamic widgets) load their listing content client-side. Instead of forcing a non-existent detail page fallback, recognizing the listing layer needs JS rendering produces cleaner code and better results.
