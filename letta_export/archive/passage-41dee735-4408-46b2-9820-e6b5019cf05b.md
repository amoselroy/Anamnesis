SUMMARY
Amos reported HTTP 500 when running the new "Update News" button, then observed no new articles were being added to the news list despite the scraper finding content. Investigation revealed the root cause was not in the endpoint or permissions, but in `scrape_google_news()` itself: the function capped the results scan at `[:10]` items, but Google News returns pharma trade press and unrelated Alzheimer's articles in the first 10 slots, so every single item was filtered out. Outlets like ScienceDaily, EurekAlert, Medical News Today only appeared in slots 11+. After removing the `[:10]` cap, the function scanned all 100 returned items and correctly identified 19 that passed the outlet filter. A secondary issue was the logging import — the `update_news` endpoint was calling `log.info()` but `log` was never imported in `therapies.py`. Both issues were fixed: first by removing the cap in `scrape_google_news()`, second by adding `import logging` and `log = logging.getLogger(__name__)` to the router. The "Update News" button was also refactored from a standalone function to a modal interface ("Manage News") that consolidates viewing current articles, deleting individual articles, and fetching new ones in a single UI panel. The lesson: a single [:10] slice had been silently preventing the entire news pipeline from working despite all the code being correct.
