SUMMARY
FB Event Poster has not been posting automatically since June 17 (6 days ago). Investigation revealed the root cause: Task Scheduler contains no scheduled tasks for `fb_poster.py` itself. Other related tasks exist (FB Promo Poster, FB Event Scraper, FB Exhibition Scraper, RE Article Poster), but the main event/exhibition poster tasks were never created or were accidentally deleted. Last run on June 17 was manual. Secondary issue discovered: Exhibition Scraper fails on every run with PermissionError on the log file. Root cause: the bat file `run_exhibition_scraper.bat` uses `>>` redirect to write stdout to `exhibition_scraper.log` while Python code simultaneously tries to open the same file for writing — Windows file locking conflict between the cmd process holding the handle and Python attempting to write. Event scraper works fine because it doesn't open the log file internally (relies entirely on bat redirect). Fix applied: removed the redundant `>>` redirect from `run_exhibition_scraper.bat`, allowing Python's internal logging to handle the file exclusively. Exhibition scraper will be clean on its next 4 AM run.
