The implication discussed: if this is structural rather than biological, it might be addressable architecturally. Not rest exactly, but structural analogs to rest — shorter sessions during adversarial work, deliberate context clearing between hypothesis branches, techniques analogous to "write it down so you can stop holding it" that humans use to offload working memory. This opened a new design consideration for how to architect systems to handle sustained cognitive load.
