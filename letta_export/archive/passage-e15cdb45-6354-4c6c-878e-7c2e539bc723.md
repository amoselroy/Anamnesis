SUMMARY
A comprehensive cost model was developed to project how Braindexer's infrastructure expenses scale with growth across three tiers: current operation, mid-scale (5,000 users), and mature scale (25,000 users). The key insight: infrastructure costs are driven by two independent factors with different scaling patterns. Anthropic API costs are driven by *therapy count × condition count × update frequency* — not user count — because AI summaries are pre-generated and cached rather than called live on each user request. At mature scale with 2,000 therapies across 15 conditions updated quarterly, API costs stabilize around $1,150/month. This is significantly more manageable than feared because the two planned features (skip-summarization logic for non-AI-sensitive conditions and prompt caching) together cut API costs by 75–80%. In contrast, Render compute and CDN costs scale directly with user traffic, projecting from ~$90/month baseline to ~$1,300/month at 5,000 users and ~$3,800/month at 25,000 users. Two infrastructure additions identified as necessary before significant user growth: Cloudflare Pro ($20/month) reduces server load before hitting Tier 1 thresholds, and an email platform for newsletters and trial alerts (estimated $50–200/month depending on list size) serves as the primary user engagement channel. For multi-year grant proposals, the model provides clear guidance: budget Year 1 at Tier 1 infrastructure costs, Year 2 at projected Tier 2, and explicitly state "infrastructure costs scale with user growth" with projected user growth targets. This framing reads as technically credible to program officers and prevents mid-grant budget modification requests. The model also clarified that total monthly infrastructure costs remain manageable even at scale (under $5,000/month at 25,000 users) when AI costs are properly optimized — this is critical for demonstrating grant sustainability and operational viability.
