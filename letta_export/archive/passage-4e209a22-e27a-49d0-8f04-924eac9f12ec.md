WORLD PATTERN 2026-06-20 — Short-circuit evaluation in conditional filters bypasses fallback checks — 2026-06-20

PRINCIPLE: Conditional filters using AND logic (`if condition_a and condition_b`) can be bypassed when condition_a is falsy (including None/NULL), preventing condition_b from being evaluated and allowing unwanted items through if condition_b was intended as a fallback safety check.

NARRATIVE: The deduplication code `if url and url in seen_urls: continue` was intended to skip papers already in the set OR allow NULL-URL papers (which don't have a dedup check) to proceed. However, when `url` is `None`, the expression short-circuits at the first AND — `None and None in seen_urls` evaluates to None (falsy) without ever checking the second condition. NULL-URL papers are added repeatedly because they never trigger the dedup skip. The issue is architectural: the code assumed URLs would always exist or be properly handled, but relied on AND short-circuiting which doesn't provide the fallback behavior intended. The fix is explicit None-checking (`if url is None or (url and url in seen_urls)`) or title-based dedup as an alternative. This pattern generalizes: filters using AND should be explicit about handling falsy values rather than relying on short-circuit side effects for safety logic.
