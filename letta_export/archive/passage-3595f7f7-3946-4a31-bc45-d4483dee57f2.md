WORLD PATTERN 2026-09-22 — API key separation for cost containment and failure-mode isolation — 2026-09-22

PRINCIPLE: Dedicated API keys for specific subsystems enable independent cost tracking and catastrophic failure isolation.

NARRATIVE: The scam-baiting bot uses a separate Anthropic API key, isolated from the shared key used across other projects (Letta, Threshold, Braindexer). The separation serves two distinct purposes: (1) cost isolation, making the bot's LLM expenses visibly distinct and auditable, enabling billing attribution; (2) failure-mode containment, because if the bot's key is burned (compromised, rate-limited, quota exhausted), the key can be independently revoked without disabling other services. The cost-transparency benefit alone justifies the separation; the failure-containment benefit makes it essential in production environments. This generalizes wherever shared resources span multiple independent subsystems: dedicated resource allocations (keys, databases, compute pools) transform cascading failures into bounded incidents and create actionable metrics for each subsystem's independent resource consumption.
