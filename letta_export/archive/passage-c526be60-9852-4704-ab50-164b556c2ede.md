SUMMARY
To resolve uncertainty about whether abstract fetching was actually helping Haiku's relevance scoring and to provide transparency into Haiku's ranking decisions, a diagnostic script (diag_ranking.py) was created to fetch all papers for a therapy, fetch their abstracts from PubMed, and call Haiku with a request for both the tier score AND the reasoning for each classification. The script would display color-coded output (green/yellow/gray for 1/2/3) with each paper's reasoning visible, allowing human evaluation of whether the scoring made sense. This addressed Amos's concern about whether abstract inclusion was actually being used by Haiku and whether the tier definitions were being applied accurately. The script required both the production database URI and the Anthropic API key to be set as environment variables. Several iterations were needed to resolve environment variable passing issues and database connection problems (local dev database vs production Neon database), but the tool was eventually functional and deployed.
