WORLD PATTERN 2026-06-25 — Single-dimensional scoring frameworks cannot represent multi-modal interventions — 2026-06-25

PRINCIPLE: Classification systems designed around a unidimensional axis (good-to-bad, simple-to-complex) become dishonest when reality is multi-dimensional and entities legitimately belong to multiple categories simultaneously.

NARRATIVE: Braindexer's therapeutic_action field used a 1-5 integer scale designed as a spectrum from disease-modifying to rehabilitative. This worked poorly when real therapies needed multiple labels — exercise is both neuroprotective and rehabilitative; gamma sensory stimulation is neuromodulatory with potential rehabilitative aspects. The scale collapsed them into a single number, losing information and forcing false choices. When the system was redesigned to use discrete multi-mode JSON arrays (Disease-Slowing, Disease-Arresting, Symptomatic, Neuroprotective, Neuromodulatory, Rehabilitative, Preventive), therapies could accurately express "this is multiple things." The pattern generalizes: whenever a classification system starts with a 1-5 scale or similar unidimensional frame, test it against the question "are there legitimate things that belong to multiple categories?" If yes, the design needs orthogonal axes or multi-label support, not a reordered scale.
