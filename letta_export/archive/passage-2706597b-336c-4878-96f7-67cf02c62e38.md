WORLD PATTERN 2026-06-11 — All_failed fallback pattern for Path B — 2026-06-11

PRINCIPLE: Path B (LLM listing extraction) should trigger not only when few links are found, but also when all found links fail extraction, catching cases where many navigation pages are found but contain no event data.

NARRATIVE: Originally Path B triggered only when `links < 4` (assumed few links meant nav pages). But venues with many navigation links (like JCTC's 9 pages) exceeded this threshold, so Path B never got a chance to run even though all the links were worthless. Extended the condition to `no_extract == found` (all found links failed extraction), which caught this case and allowed Path B's text-reading fallback to rescue the situation. The pattern generalizes: fallback conditions should be based on outcome (did the primary path actually succeed?) not just input shape (how many links were found?). A trigger based on "all attempts failed" is more robust than one based on "the input was small."
