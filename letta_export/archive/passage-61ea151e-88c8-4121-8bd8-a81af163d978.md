WORLD PATTERN 2026-06-11 — Aggregator source rotation ordering for deduplication credit — 2026-06-11

PRINCIPLE: Running aggregator sources last in a nightly scrape rotation allows primary venue sources to be credited in deduplication, preventing aggregators from shadowing the original sources where events appear in both feeds.

NARRATIVE: During systematic source testing, it became clear that aggregator sources (Hoboken Girl, Patch Hoboken, Patch JC) contain significant overlap with primary venue sources. Rather than remove aggregators, the decision was made to reorder the spreadsheet so aggregators run at the end of each nightly rotation (the scraper processes 4 sources per night by oldest Last Scraped date). This allows primary sources to be scraped and stored first, so when the deduplication logic encounters the same event in an aggregator feed later that night, the primary source is credited. This pattern generalizes to any multi-source scraping system where some sources are aggregators of others: rotation ordering can serve as a credit-prioritization mechanism without losing coverage.
