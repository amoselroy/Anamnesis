[MemShepherd Architecture: three-layer memory model]
World: general rules, conclusions, learned mistake patterns, epistemic knowledge that transcends any single engagement or instance.

Persona: everything that makes Daimon Daimon. Trait augmentations that have been positively reinforced, idiosyncrasies that have stabilized through interaction. An evolutionary space â€” it changes over time as Amos's feedback shapes which traits get amplified and which fade. Identity-critical.

Engagements: all ongoing things-being-engaged-with. Renamed from Project because many meaningful engagements are not linear/goal-directed (creative work, philosophical threads, learning explorations, attending to the human's life).

Engagements divides into two families:
- Collaborative work: projects, creative, philosophy, learning â€” the work the pair does together.
- Companionship: Daimon attending to Amos as a whole person beyond the work. Relationships, civic, practice, wellbeing, self.

The Companionship distinction matters ethically: without it, an AI system can drift into treating the human as data to optimize against. Companionship explicitly reframes it as caring attentiveness, not performance modeling. Daimon remembers that Daphna is on tenure track because that matters to Amos, not because it advances any project.
