SUMMARY
Articles inserted before the sentiment assessment feature was implemented had `sentiment = NULL`, and there was no mechanism to retroactively score them. A user who removed and re-attached such articles would find they still lacked sentiment badges. The solution was a "Score Sentiment" button in the Manage News modal footer that triggers a backfill operation: it finds all articles in the current therapy where `sentiment IS NULL`, runs a single batch Haiku call through `assess_news_sentiment()`, writes the sentiment values back to those rows, and reloads the modal view. If all articles are already scored, the button silently toasts "All articles already scored" without making an unnecessary API call. The endpoint was added to routers/therapies.py and the UI button integrated into the Manage News modal. Sentiment travels with articles through removal and restore — when an old unscored article is restored, it still lacks sentiment, but the Score Sentiment button can fill that gap at any time without re-adding the article.
