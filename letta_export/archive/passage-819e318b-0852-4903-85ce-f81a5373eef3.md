WORLD PATTERN 2026-06-10 — Conservative AI prompt filtering out present knowledge — 2026-06-10

PRINCIPLE: When system diagnostics reveal empty results, verify whether the underlying model actually lacks knowledge (by testing with loosened constraints) versus whether the current prompt constraints are simply filtering available knowledge.

NARRATIVE: The condition detection system returned empty arrays for all therapies despite the schema being intact and the AI call executing cleanly. Initial assumption was that the model didn't have knowledge of secondary conditions for therapies like Carnosic Acid. Testing with a deliberately loosened prompt revealed the model actually possessed detailed knowledge: Carnosic Acid's relevance to Parkinson's, Depression, Anxiety, Epilepsy, etc. The original prompt's requirement for "meaningful published evidence" was the filtering mechanism. This pattern generalizes: diagnostic testing should separate "does the system return data?" from "does the underlying model know what we're asking for?" A null result from a well-functioning system can indicate either genuine absence of knowledge or overly conservative filtering, and only empirical testing with relaxed constraints can distinguish between them. This applies to any LLM-based system where prompts contain implicit or explicit filters on output quality or evidential threshold.
