SUMMARY
Amos identified a limitation in brokerage_sharer: when scraping personal posts from Exit on the Hudson (like congratulations or birthdays), the main post text often contains only generic language ("Thanks for being a great member of our team. Congratulations!") while the person's name and details are only visible in attached image graphics. This prevented Claude from writing contextual comments that referenced the specific person being celebrated.

Two approaches were evaluated: (1) extracting alt text from images (unreliable, depends on Facebook's auto-generated captions), and (2) taking a screenshot of the article element and sending it to Claude Vision. The vision approach was selected as more reliable. Cost analysis showed minimal impact: each screenshot (~1000×700px) costs approximately 1,200 input tokens at $0.80/MTok plus ~30 output tokens, totaling ~$0.001 per personal post. With personal posts appearing 2–4 times per week, annual cost would be under $0.10.

Implementation added three components: `screenshot_article(page, permalink)` helper function to capture PNG bytes of the article element, an updated `generate_congrats_comment(text, image_bytes=None)` function accepting optional image bytes for vision input, and wiring into the run loop to screenshot personal posts before commentary generation. The vision prompt instructs Claude to use any visible names or details from the graphic when writing the comment. This solves the blind-spot problem with minimal cost.
