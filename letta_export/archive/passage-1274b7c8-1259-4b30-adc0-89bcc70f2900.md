SUMMARY
After image and text insertion began working, the Post button couldn't be found and posts were disappearing. The code included an `Escape` key press intended to dismiss suggestion dropdowns, but this was actually closing the entire composer dialog before the Post button search ran. Additionally, various approaches to set text focus were causing React re-renders that detached the editor DOM node, leaving `execCommand` with null targets. The issue was that each intervention (JS click on the element, dialog scoping, etc.) was triggering the composer's React state machinery to replace DOM nodes mid-execution. The solution was to remove the Escape key press, revert to the minimal working JavaScript execCommand approach without intermediate clicks, and let Playwright's built-in focus mechanisms handle the state rather than fighting React's component lifecycle.
