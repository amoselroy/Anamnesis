SUMMARY
The session concluded by removing two UI buttons that were added early but had questionable long-term utility. The global "Re-embed All" button was removed because proper model migrations would use dedicated scripts, not one-by-one UI buttons hitting rate limits — individual per-therapy re-embed buttons were preserved for rare refresh cases. The global "Backfill Relevance" button (added for scoring sources that existed before the relevance feature) was also removed since the feature is now built into every Research run and can always be re-run if needed. In their place, a per-therapy "Rank Papers" button was added to each therapy row, which triggers a fast synchronous Haiku scoring call over just that therapy's papers, completing well under the 30-second timeout and returning immediately with updated relevance scores. This approach keeps the ranking capability available without maintaining a global async operation that would rarely be used.
