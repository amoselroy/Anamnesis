SUMMARY
When the diagnostic script revealed 315 papers for Sauna therapy, investigation of the `research_therapy()` deduplication logic uncovered the core issue: papers with NULL URLs were bypassing the `seen_urls` set-based deduplication check. The code `if url and url in seen_urls: continue` evaluates to False when `url` is None, allowing NULL-URL papers to be re-inserted on every research run. ICTRP trials without a `web_address` field are the primary source of NULL-URL entries. The fix involved three components: (1) add title-based deduplication as a fallback when URL is missing, (2) implement `ON CONFLICT DO NOTHING` at the INSERT level with a UNIQUE constraint on (therapy_id, url) using a partial index to handle NULL URLs, (3) fix the startup migration to create the unique index successfully by working on a clean table. The deduplication code was refactored to check title alongside URL, and the INSERT statement was updated with explicit conflict handling. Additionally, a `flush_sources.py` utility was created to safely remove papers/articles/trial_registrations from the database while preserving news articles (different source_type), supporting both targeted (single therapy) and full (`--all`) flush modes.
