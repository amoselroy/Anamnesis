WORLD PATTERN 2026-06-04 — Constitutional Amendment as fixed framework versus operational config — 2026-06-03

The Amendment is intended as a stable philosophical framework to be published to the Letta forum for adoption by other developers, not as a frequently-updated configuration file. The distinction is fundamental: a constitution shouldn't be hot-reloaded. Automatic syncing would degrade it from a deliberate philosophical document into a config file that drifts silently. For other developers adopting the Amendment, pulling a version and implementing it is a conscious choice — they shouldn't have updates come under them. This led to the design of push_amendment.py as a one-off utility tool that PATCHes the Letta agent's system prompt deliberately at version milestones, with dry-run-by-default behavior to prevent accidental pushes. The Amendment loads into the protected system field at the top of every Letta context window (never truncated or reordered), serving as the permanent operating philosophy while operational guidance (like three-level world extraction) belongs in code (chunk_archive.py) not in the constitutional document.
