SUMMARY
To automate the posting process, two separate scheduled tasks were created using Windows Task Scheduler (`schtasks` commands):

1. **Events Task** — runs daily at 7:00 AM with `--events-only` flag, posting all events within the 3-day advance window
2. **Exhibitions Task** — runs every 3 days at 8:00 AM with `--exhibits-only --exhibit-limit 7` flags, posting up to 7 exhibitions per run

The 1-hour time gap (7 AM vs. 8 AM) ensures the two tasks don't overlap on days when both are scheduled. The tasks run under SYSTEM context so they execute even when the user is not logged in.
