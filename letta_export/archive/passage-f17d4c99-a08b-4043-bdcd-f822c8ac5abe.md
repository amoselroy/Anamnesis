WORLD PATTERN 2026-06-06 — Three-level audience design as content architecture pattern — 2026-06-07

PRINCIPLE: Structure core content in three parallel versions targeting different expertise levels (clinical precision, informed-individual, layperson) as a fundamental architecture rather than an afterthought UX feature.

NARRATIVE: Braindexer's design made the three-level summarization (clinical for physicians, informed individual for engaged patients, layperson for general readers) central to the database schema and the scraping/synthesis pipeline, not an optional view. This isn't translation — it's parallel authoring at different epistemic levels. The same therapy entry has three independent summaries generated from source material by prompts tuned to each audience's needs and sophistication. This pattern works because: (1) it forces clarity about what each audience actually needs to know, (2) it generates content simultaneously rather than starting with one level and dumbing down, (3) it naturally attracts credibility across all audiences (seeing rigorous clinical work builds trust for layperson summaries). The pattern generalizes to any domain where the same information serves different expertise levels.
