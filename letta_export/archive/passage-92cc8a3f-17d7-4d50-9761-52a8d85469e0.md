WORLD PATTERN 2026-06-04 — Layered fallthrough architecture for cost-efficient extraction across heterogeneous sources — 2026-06-03

When building a scraper across 44+ sources with no standard schema (each using different HTML structures, JS frameworks, or embedded third-party tools), attempting to build a single universal parser fails. Instead, implement a layered fallthrough where each path targets a specific extraction method: Path A for static HTML/JSON-LD (zero cost, ~2 seconds), Path B for LLM-based extraction on listing pages (cheap but selective, ~$0.01 Haiku per hard case), Path C for Playwright JS rendering (moderate cost, ~5-10 seconds), specialized paths for known patterns (e.g., Facebook events), then graceful fail. The economic insight: this architecture keeps nightly cost to ~$0.01-0.03 by only invoking the expensive Haiku layer when static parsing fails, while guaranteeing extraction across all sources. The principle extends beyond scrapers — when facing heterogeneous data sources, layered fallthrough with increasing cost/sophistication per layer is more efficient than both "one-size-fits-all" parsers and source-specific custom code.
